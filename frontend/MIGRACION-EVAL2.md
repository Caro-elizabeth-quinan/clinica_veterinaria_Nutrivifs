# Evaluación Parcial 2 — Clínica NutriDifs

## Tecnologías
- React + TypeScript
- Vite
- React Router
- Bootstrap 5
- LocalStorage para la persistencia académica del navegador

## Ejecutar
1. Instala Node.js LTS si no está instalado.
2. Abre una terminal dentro de la carpeta `frontend`.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la URL local que indique Vite.
